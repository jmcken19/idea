# Ideas and brainstorming (Mode A)

The default space. Bring anything: a half-formed thought, an observation, a "what if", a "why doesn't X exist?".

Brainstorming happens in conversation. Nothing is written here unless you say "save this", "note this" or similar. Then one short note is saved as `ideas/<slug>.md` (`python3 tools/ir.py note <slug> "<idea>"`), using `templates/idea-note.md`: the idea in your words, angles explored, open questions, and what would be worth checking.

When an idea gets interesting enough, ask for a **deep validation** (Mode B). It then gets a formal record in `validations/`.
