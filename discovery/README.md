# Opportunity discovery

Scans that look for opportunities the founder hasn't brought up, run only on request (`/discover <area>`). Each scan is one file, `discovery/YYYY-MM-DD-<area>.md`, from `templates/discovery-scan.md`.

What a scan looks for: emerging infrastructure, new launch mechanisms, underserved users of existing products, changing protocol economics, recurring developer and community pain, tools that could be combined in new ways, and poor user experiences.

**Rule: a gap is not demand.** For every candidate, the scan separates "nobody has built this" (which proves nothing) from evidence that people want it: requests, workarounds, money spent on poor substitutes.
