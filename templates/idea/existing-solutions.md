### Differentiation test (only if an equivalent exists)

Answer each with evidence, not argument:

1. What, specifically, would a customer get that the existing option does not give them?
2. Is there evidence that customers want that difference (complaints, requests, paid workarounds)?
3. Could the incumbent ship that difference within one release? (If yes, it is a feature, not a company.)
4. Is the difference something you would still pitch if the incumbent did not exist?

If 1 or 2 has no evidence, **stop: REJECTED** (write final-verdict.md; skip Stages 4–5).
